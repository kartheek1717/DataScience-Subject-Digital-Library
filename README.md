# Data Science Subject Digital Library & Virtual Laboratory

A modern, interactive Virtual Laboratory and Digital Resource Hub built for the **B.Tech Data Science** curriculum at **Mohan Babu University**.

---

## 🚀 Overview

This platform serves as a complete digital companion for Data Science students and educators, combining interactive laboratory experiments, real-world machine learning project showcases, curriculum-aligned academic resources, and student portfolio management.

### Key Capabilities

* 🧪 **10 Full Laboratory Experiments**: Complete with comprehensive theory, execution scaffolding, reproducible Python code, interactive tabular dataframes, statistical charts, and autograding indicators.
* 📂 **Projects Catalog**: Showcase of end-to-end applications including **BTC AI Trader** (Automated Cryptocurrency Trading Platform) and **Block Survive** (Interactive 2D Canvas Web Game), plus applied ML pipelines.
* 📄 **Curriculum Vitae & Student Portfolio**: Dual-mode resume system featuring a clean **ATS Paper View** (with instant print-to-PDF formatting) and an **Interactive Portfolio View** with live skill matrices and verified academic benchmarks.
* 📚 **Tools & Digital Library**: Curated cheatsheets, Python vectorization guides, dataset catalogs, and interactive documentation for NumPy, Pandas, Scikit-learn, and PyTorch.
* 🌓 **Dark & Light Mode**: Built-in theme customization, persistent local storage, and responsive design for desktop and mobile form factors.

---

## 🛠 Tech Stack

* **Framework**: React 19 + TypeScript + Vite
* **Styling**: Tailwind CSS + Lucide Icons
* **Data & State**: React Context API (`LabContext`) with automatic local storage synchronization
* **Data Visualization**: Recharts / Canvas Rendering
* **Build System**: Vite 6 / ESBuild

## 📦 Getting Started

### Prerequisites

* Node.js (v18 or higher recommended)
* npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/kartheek1717/DataScience-Subject-Digital-Library.git

# Navigate to the project directory
cd DataScience-Subject-Digital-Library

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available locally at `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```
